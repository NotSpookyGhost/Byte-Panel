Runtime

Start this configured Minecraft server once when the panel/container starts. Saving this option does not start Minecraft immediately. Both automatic options are off by default.

Restart a panel-managed server after an unexpected non-zero exit, with a 10-second delay. Stop buttons, console stop commands and clean shutdowns stay stopped. Recovery waits for backups and file operations. After 3 restart attempts within 5 minutes, use Start manually after checking the logs.

By default, the backend automatically targets specific OpenJDK binaries inside the container based on your Minecraft version.
Used for formatting time on the panel.
Show system debug output in the server console.

Backups

Applies to manual and scheduled backups. Players will be disconnected while Minecraft shuts down, the archive is created and verified, and the server starts again. A server that was already offline stays offline.

If shutdown does not finish within 3 minutes, the backup is cancelled without force-killing Minecraft. After a clean shutdown, the panel also attempts to restart if creating the archive fails. Users with backup creation permission can trigger this downtime.
