Plugins & files

Upload plugin JARs to the plugins folder, then start or restart your server to generate their config folders.

Open a plugin folder below to upload presets, compressed exports or other data files into it. Files are stored unchanged, not extracted or imported automatically.

Stop the server before editing configs, replacing files in use or deleting plugins. Restart for JAR changes; follow each plugin's instructions for config reloads and data imports. Deleting a JAR keeps its config folders and saves a recoverable backup.

Data/config destination: plugins/ (open a plugin subfolder for data files).

JARs always go in the root plugins folder (64 MiB max). Non-JAR files go in the folder you have open: up to 64 MiB in subfolders, or supported text configs up to 1 MiB in the root. The text editor remains limited to 1 MiB.

LuckPerms: open plugins/LuckPerms and upload your exported preset.json.gz. Then, with the server running, use lp import preset.json.gz in the console to merge it. Uploading alone does not change permissions.
