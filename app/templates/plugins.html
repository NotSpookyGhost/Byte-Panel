File limits, safety & import guidance

Upload {{ addon_kind }} JARs to the {{ root_name }} folder, then start or restart your server to generate their configs.

Open a {{ addon_kind }} folder below to upload presets, compressed exports or other data files into it. Files are stored unchanged, not extracted or imported automatically.

Stop the server before editing configs, replacing files in use or deleting {{ root_name }}. Restart for JAR changes; follow each {{ addon_kind }}'s instructions for config reloads and data imports. Deleting a JAR keeps its config folders and saves a recoverable backup.

JARs always go in the root {{ root_name }} folder (64 MiB max). Non-JAR files go in the folder you have open: up to 64 MiB in subfolders, or supported text configs up to 1 MiB in the root. The text editor remains limited to 1 MiB.
